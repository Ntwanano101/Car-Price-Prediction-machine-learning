# Used Car-Price-Prediction-machine-learning
Used Car Price Prediction Using Machine Learning
Project Overview:
This project uses machine learning techniques to predict used car prices based on historical vehicle data.

Dataset
The project uses approximately 15,411 used-car records.

Tools and Technologies:
.Python
.Pandas
.NumPy
.Matplotlib
.Scikit-learn
.Jupyter Notebook

Data Preparation:
.Removed duplicate records.
.Identified and handled invalid records.
.Performed data cleaning and preprocessing.
.Transformed skewed variables.
.Encoded categorical features.

Machine Learning Models
The following models were developed and compared:
.Linear Regression
.Decision Tree
.Random Forest
.Gradient Boosting

Results:
.Gradient Boosting achieved the best model performance, with an R² score of approximately 0.885 and an RMSE of approximately R80,381.

Key Learning Outcomes:
.Data cleaning and preprocessing
.Exploratory data analysis
.Feature engineering
.Regression modelling
.Model evaluation and comparison

Conclusion:
This project demonstrates practical skills in Python, data analytics and machine learning, particularly in developing and evaluating predictive models.
